# Data Related Sections

## .BSS Section

初期化されていないグローバル変数に対応するセクションです。このセクションは ELF ファイルの領域を占めませんが、プログラムのメモリイメージ内の領域は占めます。プログラムの実行が始まると、システムはこれらのデータを 0 に初期化します。bss は実は block started by symbol の略です。

## .data Section

これらのセクションは初期化済みのデータを含み、プログラムのメモリイメージに現れます。

## .rodata Section

これらのセクションは読み取り専用のデータを含みます。このデータは通常、プロセスイメージの書き込み不可のセグメントに属します。
