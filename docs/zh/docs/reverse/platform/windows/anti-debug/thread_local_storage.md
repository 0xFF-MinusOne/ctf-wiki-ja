# Thread Local Storage(TLS)

スレッドローカルストレージ(TLS)は、スレッドが開始する前に、特定のスレッドのデータを初期化するために使われます。どのプロセスにも少なくとも1つのスレッドがあるため、メインスレッドが動作する前にデータを初期化します。初期化は、動的に確保されたメモリへコピー済みの静的バッファを指定することと、またはコールバック関数の配列の中でコードを実行することによって、動的メモリの内容を初期化して行えます。問題が生じるのは、たいていコールバック関数の配列が悪用されたためです。

実行時に、TLS コールバック関数の配列の内容は変更したり追加したりでき、新しく追加・変更されたコールバック関数は新しいアドレスで呼び出されます。コールバック関数の数にも制限はありません。配列の拡張は、次のコードで行えます。

``` asm
l1: mov d [offset cbEnd], offset l2
    ret
l2: ...
```

l1 のコールバックが戻ると、続けて l2 のコールバック関数が呼び出されます。
