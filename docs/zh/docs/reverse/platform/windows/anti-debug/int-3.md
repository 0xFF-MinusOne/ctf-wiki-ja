# Interrupt 3

ソフトウェア割り込み例外が発生すると、例外アドレスと EIP レジスタの値は、どちらも例外を起こした命令の次の命令を指します。ただしブレークポイント例外は、その中の特別な例外です。

`EXCEPTION_BREAKPOINT(0x80000003)` 例外が発生すると、Windows はこれが1バイトの「`CC`」オペコード(つまり `Int 3` 命令)によるものだと判断します。Windows は例外アドレスを1つ減らして、そう判断した「`CC`」オペコードを指すようにし、その例外を例外ハンドラに渡します。しかし EIP レジスタの値は変化しません。

そのため、`CD 03`(これは `Int 03` のマシンコード表現です)を使うと、例外ハンドラが制御を受け取ったとき、例外アドレスは `03` の位置を指しています。
